# Evaluation

Evaluation biến câu hỏi mơ hồ “model có tốt không?” thành một decision system: định nghĩa success, tạo evidence phù hợp, đo đúng dimensions và dùng kết quả để quyết định release hoặc cải thiện.

## Topic Overview

Mental map: **Task success → Evaluation method → Test cases → Metrics → Reliability → Regression gate**. Mỗi layer trả lời một câu hỏi khác nhau; landing page này chỉ giúp định hướng giữa các layers.
