# Context Engineering

Context Engineering là việc quyết định **information nào cần xuất hiện cho current decision, ở dạng nào và trong invocation nào** — không phải chỉ tăng prompt hoặc context window.

## Topic Overview

**Mental model:** Context Window là cái bàn; Context là những thứ đặt trên bàn; Context Engineering là chọn đúng thứ cần đặt lên bàn cho quyết định hiện tại.
