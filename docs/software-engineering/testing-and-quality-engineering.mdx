# Testing & Quality Engineering

Testing & Quality Engineering giúp đặt test ở boundary nhỏ nhất có thể chứng minh behavior cần bảo vệ, rồi bổ sung broader tests khi cần xác nhận integration hoặc user journey.

## Topic Overview

Mental map: **Unit → Integration → End-to-End** tăng scope và confidence theo boundary, nhưng thường cũng tăng setup cost, execution time và độ khó khi debug failure.

- [Testing Fundamentals](./testing-fundamentals) — chọn Unit, Integration hay E2E theo risk boundary.
- [Test Doubles & Mocking](./test-doubles-and-mocking) — phân biệt Stub, Mock và Fake theo mục đích của test.
