# System Design

System Design là reasoning process để biến requirements thành architecture có explicit bottlenecks, trade-offs, failure modes và operational boundaries.

## Topic Overview

Mental map: **Requirements → Workload / bottleneck → Building blocks → Trade-offs → Failure & recovery**. Các case studies áp dụng cùng reasoning process vào constraints khác nhau.
