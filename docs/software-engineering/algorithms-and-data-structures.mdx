# Algorithms & Data Structures

Algorithms & Data Structures giúp chọn representation và traversal strategy phù hợp với operation cần tối ưu thay vì ghi nhớ thuật toán rời rạc.

## Topic Overview

Mental map hiện tại đi từ **find/order → direct lookup → linear access discipline → connected structures & traversal**.
