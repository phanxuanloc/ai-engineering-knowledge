# Networking & Web Fundamentals

Networking & Web Fundamentals giúp debug theo **boundary đầu tiên mà request chưa vượt qua**, thay vì gom mọi failure thành “API lỗi”.

## Topic Overview

Mental map: **Resolve Destination → Reach Destination → Establish Communication → Process Request → Response**. Đây là logical lifecycle, không phải topology bắt buộc của mọi hệ thống.
