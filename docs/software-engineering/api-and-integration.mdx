# API & Integration

API & Integration tập trung vào cách hai systems trao đổi capability và data qua một contract rõ ràng, với trade-offs phù hợp cho từng communication boundary.

## Topic Overview

Mental map: **Caller needs → Contract → Communication style → Operational trade-offs**. REST, gRPC và GraphQL là choices theo boundary, không phải một ranking chung.
