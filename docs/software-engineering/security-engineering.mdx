# Security Engineering

Security Engineering bắt đầu từ **thứ cần bảo vệ** và các đường mà untrusted actors, input hoặc compromised components có thể tác động tới nó.

## Topic Overview

<KnowledgeMap
  label="Security Engineering topic map"
  levels={[
    [{title: 'Assets', description: 'Identify the data, capability and system behavior that must be protected.'}],
    [{title: 'Threats', description: 'Identify actors, misuse cases and failure paths that can harm those assets.'}],
    [{title: 'Attack Surface', description: 'Locate exposed entry points and trust boundaries where threats can reach the system.'}],
    [{title: 'Controls', description: 'Apply prevention, detection and containment controls at the right boundaries.'}],
    [{title: 'Residual Risk', description: 'Evaluate what remains possible and limit blast radius when a control fails.'}],
  ]}
/>
