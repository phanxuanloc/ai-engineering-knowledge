# Security Engineering

Security Engineering bắt đầu từ **thứ cần bảo vệ** và các đường mà untrusted actors, input hoặc compromised components có thể tác động tới nó.

## Topic Overview

Mental map: **Assets → Threats → Attack Surface → Controls → Residual Risk**. Thiết kế tốt không chỉ ngăn failure mà còn giới hạn blast radius khi một control thất bại.
