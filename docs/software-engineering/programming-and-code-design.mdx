# Programming & Code Design

Programming & Code Design tập trung vào một câu hỏi: **làm sao để một thay đổi cục bộ không lan thành thay đổi trên toàn hệ thống?**

## Topic Overview

Mental map: đặt responsibility đúng chỗ, expose capability qua abstraction phù hợp, giữ implementation details encapsulated và chọn dependency structure làm change impact nhỏ nhất.
