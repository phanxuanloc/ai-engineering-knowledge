# Programming & Code Design

Programming & Code Design tập trung vào cách đặt trách nhiệm và dependency để một thay đổi cục bộ không lan ra toàn hệ thống. Các note canonical đã được tách theo mental model và practical purpose:

- [Coupling & Cohesion](./coupling-and-cohesion.mdx) — nhận diện module ôm nhiều trách nhiệm và phụ thuộc trực tiếp vào quá nhiều chi tiết.
- [Abstraction & Encapsulation](./abstraction-and-encapsulation.mdx) — phân biệt capability được expose với implementation detail được che giấu.
- [SOLID as Design Lenses](./solid-design-lenses.mdx) — dùng SOLID để reasoning về change impact thay vì áp dụng máy móc.
- [Composition vs Inheritance](./composition-vs-inheritance.mdx) — chọn `HAS-A` / `USES-A` cho capability có thể thay thế độc lập và giữ inheritance cho quan hệ `IS-A` thật sự.
